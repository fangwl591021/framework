# Known Limitations

- Local Demo Candidate；Not Deployed；Production Use Not Allowed。
- Deterministic intent resolver only；無 AI provider、語音或自然語言生成。
- 只提供 allowlisted fixture context，沒有登入、正式 identity adapter 或多裝置 session。
- 無 LINE/LIFF、Telegram、Remote D1、Queue、Cron、Durable Object、正式金流或公開 API。
- Local traffic adapter 是已標示 local-test-only 的 allow adapter；不是 Production coordination。
- UI 是 MVP 展示層，不是 SaaS 後台或完整無障礙/國際化產品。
