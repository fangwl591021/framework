# Contract

AI Gateway 只接受 Trusted Runtime Context 與版本化 Task Contract。固定管線為 Traffic Admission、Application／Module／Permission、AI Policy、Budget、Shortcut／Cache、Route、Adapter、Output Validation、Usage Evidence。

禁止 arbitrary prompt、任意 model／endpoint、raw provider response 與授權覆寫。Domain Service 對結果保有最終商業驗證與 confirmation authority。
