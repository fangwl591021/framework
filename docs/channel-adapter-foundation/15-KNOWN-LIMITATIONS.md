# Known Limitations

- Only a deterministic Local Web adapter is executable.
- LINE, Telegram, and generic webhook adapters are disabled.
- No provider delivery, network retry, queue, cron, scheduler, or background reconciliation runs.
- No production credential, binding, endpoint, Remote D1, migration execution, or deployment exists.
- Local delivery evidence proves framework behavior, not third-party acceptance.
- Real provider payload schemas, signature vectors, capabilities, privacy terms, quotas, and outage procedures require independent review.
- Lifecycle remains Candidate and production use is prohibited.
