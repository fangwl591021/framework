## Scope

This phase defines immutable plan snapshots, a non-executable transport shape, planned credential references, bounded webhook ingress requirements, an exact symbolic egress allowlist, provider failure classification, test evidence, approval gates, and deterministic entry/exit decisions.

## Non-goals

It does not add a LINE SDK, secret value, credential provider, public route, hostname-backed transport, outbound HTTP, Remote D1, migration, binding, queue, cron, deployment, runtime composition, Production wiring, or any Provider/Canary/Sandbox authority. Fake/local verification is the only execution in scope.
