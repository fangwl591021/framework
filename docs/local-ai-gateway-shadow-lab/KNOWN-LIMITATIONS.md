# Known Limitations

- The Lab is local development software, not a production feature.
- Provider attempts are deterministic local simulations; no external provider network behavior or credential lifecycle is tested.
- Cost is an estimate and is not billing evidence.
- Budget fixtures mutate isolated local rows and are not an operator control plane.
- Reset is synchronous and scoped to the selected local Tenant/Application evidence.
- The UI uses simple CSS tables and bars; it has no analytics library or live streaming.
- Scenario timelines describe safe local attempts, not external provider telemetry.
- No Remote D1, production binding, deployment, provider management UI, API key input, LINE/LIFF, Telegram, browser extension, billing, or payment exists in this PR.
