# Local Failure Drills

The Local Lab provides 15 allowlisted, deterministic, network-free, replayable drills for lifecycle, compliance, region, retention, Secret readiness, ceilings, kill switches, plan expiry, rollback, excessive cost, unsafe output, and credential compromise.

Every result carries a safe timeline, expected outcome, readiness finding, `authority: none`, and explicit evidence that no Provider network, Secret, or Production state was used.
